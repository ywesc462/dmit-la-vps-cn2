## 洛杉矶这三条线，差的不只是价格

DMIT 洛杉矶在售的分三档，名字分别是 Premium（Pro）、Eyeball（EB）、Tier 1（T1）。三者的区别在线路，不在 CPU 和硬盘。

Pro 系列是最高一档。电信、联通去程直接走 CN2 GIA（AS4809），移动去程走 CMI（香港移动 AS58453），三网回程全部 CN2 GIA，IPv6 走 CMIN2。这里说的 CN2 GIA 是中国电信国际精品网的顶级档，去程和回程都走 AS4809，和那种只有回程走 GIA 的“普通 CN2”不是一个东西。有评测在不同时段反复跑过路由追踪，回程确实是 59.43 开头的节点，没有绕日本。

EB 系列三网回程走 CMIN2，也就是中国移动国际精品网，电信和联通去程也做了优化。对移动用户来说，这条线的延迟表现有时比 CN2 GIA 还好一些。

T1 是国际线路，不做中国大陆专属优化，带宽最高给到 10Gbps。它的定位不是给国内访问提速，而是给面向海外用户的服务、或者需要一台大带宽中转机的场景。公开资料里 T1 的入门档是 1 核 1G、20G SSD、1TB 月流量、4Gbps 带宽、年付 $36.9，超出月流量后转为限速不限量，不停机。

三条线都支持 IPv4 + IPv6 双栈、KVM 虚拟化，标配 1 个 IPv4 和 1 个 IPv6 /64。硬件平台是 AMD EPYC 加企业级 SSD，有搜索摘要提到洛杉矶机房已经升级到新平台、单核性能比旧平台提升明显，这条我没找到官方公告，只当参考。

## 160ms 是什么水平，什么时候该放弃洛杉矶

洛杉矶到中国大陆，150–165ms 是这条线路物理距离能跑出的正常值，不是线路差。

光在光纤里的速度大约是每毫秒 200 公里，中美之间光缆走一万多公里，单程传输就要 50ms 上下，一个来回 100ms 打底。再加上中间路由设备逐跳处理、跨境出口排队，150–160ms 属于偏好水平。想看 50ms 以内的数字，得换香港或者东京节点，那是物理距离决定的，跟洛杉矶机房的线路质量无关。

具体到三网，多个来源的数据量级一致：非高峰时段三网平均 155–165ms；晚高峰电信 155–160ms、联通 160ms 出头、移动 165ms 以内；丢包率长期在 0.1% 以下，三网全 0 丢包是常态。有评测连续 72 小时 ping，丢包率基本没超过 0.1%。另一位评测者的对比是，之前用的“号称 CN2”的机器晚高峰经常跑到 250ms 以上。

这个延迟拿来搭代理、看视频、开网页、下载文件，感知不强。打国际服竞技类游戏要另算，那点差距是能感觉出来的。

## 一年到底花多少钱：几个容易算错的地方

**年付和月付不能直接比单价。** 两套命名对应两套配置，前面已经说过。硬要比单位流量的价格，按这组评测价算：WEE 年付 $36.9 对应每月 500GB，折合每 TB 约 $6.2；月付 TINY $14.9 对应每月 1TB，折合每 TB 约 $14.9。年付档的单位流量便宜一半多，代价是带宽从 1Gbps 降到 500Mbps、突发能力弱一些。

**流量超了不停机。** 这是 DMIT 比较少见的一个设定：超出月流量后直接降速，机器继续在线。年付档的规则是 WEE 和 MALIBU 降到 2Mbps，PalmSpring 及以上降到 4Mbps。2Mbps 大概就是能收消息、能 SSH、网页要等一等的水平，4Mbps 能撑日常轻度使用。对偶尔流量跑超的人来说，这比直接停机友好得多；对流量需求本来就大的人来说，别指望限速状态下干活。

**续费价要在结算页确认。** 资料里没有官方口径说明续费是否与首期同价。第三方文章提到的循环折扣码，另一篇评测直接说“第三方流传的优惠码大多已过期或无效”，两边打架，我不在这里列码。结算页能试填就试，填完看实际扣款金额，别按文章里的折扣去算预算。

**换 IP 有成本。** 每 15 天可以免费申请换一次 IP，其他情况 $5 一次。IP 被墙是这类机器最常见的意外支出，频率高的话这笔钱要算进去。

## FAQ

**晚高峰会不会掉速？**

按多位评测者的测试结果，洛杉矶 Pro 晚高峰三网延迟基本维持在 155–165ms，最差一次没超过 180ms，丢包率 0.1% 以下。这个“稳”是 CN2 GIA 相对普通线路最核心的差别，也是它贵的原因。

**移动宽带选 Pro 还是 EB？**

优先 EB。回程 CMIN2 是移动自己的精品网，延迟表现未必输给 CN2 GIA，价格在同档位通常更低。只有当你对电信、联通方向的访问也有要求，才需要加钱上 Pro。

**流量跑超了会怎样？**

不停机，降速继续用。WEE 和 MALIBU 降到 2Mbps，PalmSpring 及以上降到 4Mbps。轻度使用还能撑，别指望限速状态下跑大流量任务。

**能解锁 Netflix、Disney+、TikTok 吗？**

全系是美国原生 IP，这类流媒体大概率能解。官方不保证，平台的风控规则也在变，以下单后自己的实测为准。需要美国原生 IP 注册 Google 服务、跑 API 的场景，原生 IP 的成功率确实比一般数据中心 IP 高。

**洛杉矶和香港怎么选？**

看你对延迟的容忍度。香港物理距离近，延迟低一档，价格通常更贵，晚高峰同样可能拥塞。洛杉矶胜在线路稳定、单价低，150–165ms 对绝大多数日常用途够用。

**Pro 和 EB 能不能互转？**

不能跨系列升级，只能重新买。同系列内可以升，比如 EB.TINY 升到 EB.Starter。
